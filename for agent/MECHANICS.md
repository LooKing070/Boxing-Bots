# МЕХАНИКИ, БАЛАНС, ДАННЫЕ, ПРОИЗВОДИТЕЛЬНОСТЬ — «Boxing-Bots»
Файл: MECHANICS.md | Версия 5.1
Единственный источник чисел (§8–9). Имена DAT_*/PERF_* генерируются в shared/constants.

## 1. МАТЧ И ПОБЕДА
MEC-1.1 Длительность MATCH_DURATION_S; таймер в HUD (SCN-4.1).
MEC-1.2 Нокаут: HP Материнской платы ИЛИ Аккумулятора ≤ 0 (включая их отсечение, MEC-2.7)
→ немедленная победа атакующего.
MEC-1.3 По очкам: по истечении времени побеждает больший суммарный урон; равенство — ничья.
MEC-1.4 Суммарный урон = весь урон по кубикам противника, включая возвращённый контрударом.
MEC-1.5 Комбо/серий/множителей НЕТ (TZ-6.2).

## 2. УРОН, ПОРОГИ, ОТСЕЧЕНИЯ
MEC-2.1 Порядок слоёв: обшивка → скелет → внутренние компоненты (spherecast по глубине, ARC-8.1).
MEC-2.2 Пороги компонентов: Цел HP ≥ THRESHOLD_DAMAGE·maxHP; Повреждён 0 < HP < THRESHOLD_DAMAGE·maxHP;
Уничтожен HP ≤ 0.
MEC-2.3 «Повреждён»: дебафф (MEC-2.5) + надпись 2 с (SCN-4.4) + VFX (STYLE §4).
MEC-2.4 «Уничтожен»: кубы компонента удаляются из модели и становятся мусором (DebrisPool);
Материнская плата/Аккумулятор → нокаут (MEC-1.2); Гироскоп/Камеры → усиленный дебафф, бой продолжается.
MEC-2.5 Таблица дебаффов:
| Компонент | Повреждён | Уничтожен |
|---|---|---|
| Материнская плата | задержка ввода DEBUFF_INPUT_DELAY_MS; глитч модели | нокаут |
| Аккумулятор | сила удара ×DEBUFF_FORCE_MULT; тусклые глаза | нокаут |
| Гироскоп | скорость ×DEBUFF_SPEED_MULT; wobble | скорость ×DEBUFF_SPEED_MULT_DESTROYED; сильное шатание с ноги на ногу |
| Камеры | виньетка; искры из глаз | сильная виньетка+шум |
MEC-2.6 Скелет: currentScale = 1 − damageTaken/maxHP (равномерно XYZ, центр сохраняется);
scale ≤ 0 → куб уничтожен.
MEC-2.7 Отсечение (Limb Detachment): уничтожение куба скелета отсекает все дочерние кубы
скелета и привязанной обшивки ниже по иерархии графа (корень = грудь/таз).
ВНУТРЕННИЕ КОМПОНЕНТЫ ТОЖЕ МОГУТ ОТСЕКАТЬСЯ: каждый компонент прикреплён в графе к скелету
своей части; при отсечении несущей части (или уничтожении опорного куба скелета части)
компонент отваливается вместе с ней и СЧИТАЕТСЯ УНИЧТОЖЕННЫМ (эффекты MEC-2.4/2.5, включая
нокаут для материнской платы/аккумулятора). Примеры: локоть → предплечье+кисть; бедро → нога;
шея → голова вместе с камерами (бой продолжается только если камеры не были нокаут-условием —
камеры не нокаут, значит бой продолжается с эффектом уничтоженных камер); грудь с материнской
платой → нокаут.
MEC-2.8 Отсечённые части (включая компоненты) — независимый мусор: DebrisPool, sleep
DEBRIS_SLEEP_S, удаление DEBRIS_LIFETIME_S, урона не наносят, предупреждений нет.
MEC-2.9 Последствия отсечений: нет руки → удары этой рукой по MEC-3.7; нет ноги →
скорость ×DEBUFF_NOLEG_MULT; нет головы → эффект уничтоженных камер.
MEC-2.10 НОКДАУН: если нога отсечена И нанесено попадание по любому внутреннему
компоненту → бот падает на KNOCKDOWN_S (управление/удары/блок недоступны, F5), затем
встаёт. Попадания по упавшему засчитываются обычно.

## 3. УДАРЫ
MEC-3.1 Пресет: слот, рука, СИЛА (2–10), кадры 1–6: точка (X/Y/Z) + длительность 0.2–1.0 с.
MEC-3.2 Траектория: стойка → кадры по прямым → возврат в стойку за ACTION_GAP_MS.
Урон: q = ((t_avg − FRAME_DUR_MIN)/(FRAME_DUR_MAX − FRAME_DUR_MIN))², t_avg = Σd / n;
damage = clamp(STR_DMG_MIN + (force − STR_DMG_MIN)·q, STR_DMG_MIN, STR_DMG_MAX) (F4).
MEC-3.3 Хитбокс кулака фиксирован (FIST_HITBOX_SIZE), активен на пути кадров; каждый куб
противника поражается ≤1 раза ОТ КАЖДОГО КУЛАКА за выполнение; урон — только при прямом
контакте куба-хитбокса с кубом цели;
MEC-3.4 Кулдауны: слотовый STRIKE_COOLDOWN_MS от конца удара; глобальный ACTION_GAP_MS
между любыми ударами/блоками (= фаза возврата руки, F6).
MEC-3.5 Knockback: KNOCKBACK_BASE как добавка горизонтальной скорости (юнит/с) с затуханием;
= 0 при сработавшей «Контратаке»; «Усиление» knockback не обнуляет.
MEC-3.6 Тело изгибается за бьющей рукой (STY-3.5).
MEC-3.7 Удар отсечённой рукой: бот «пытается» (анимация остатком), хитбокс = куб скелета
(VOXEL_SIZE), смещён к краю уцелевшей части; сила и кадры применяются как обычно.

## 4. БЛОКИ И СТАМИНА
MEC-4.0 БЛОК НЕ ДАЁТ НЕУЯЗВИМОСТЬ: любой попавший удар наносит урон. Блок лишь даёт баффы,
и баффы действуют ТОЛЬКО если удар пришёлся по рукам обороняющегося, участвующим в позе блока
(плечо/предплечье/кисть соответствующей руки). Попадания в другие части — полный урон без баффов.
MEC-4.1 Блок занимает слот A–D вместо удара; активация — зажатие.
MEC-4.2 Стамина: макс STAMINA_MAX; тап (<1 с) −STAMINA_TAP_COST; удержание
−STAMINA_HOLD_COST_PER_S за полную секунду; реген +STAMINA_REGEN_PER_2S за 2 с вне блока;
0 → прерывание. Полоска над ботом (SCN-4.3).
MEC-4.3 Баффы (комбобокс в редакторе; величины редактируются, SCN-2.1):
А «Усиление/Укрепление»: урон попавшего по рукам удара ×(1 − BLOCK_REDUCTION/100)
(дефолт BLOCK_REDUCTION_DEFAULT_PCT=35); knockback сохраняется.
Б «Контратака/Контрудар»: атакующему возвращается BLOCK_RETURN% (дефолт 8) от урона этого
удара — в случайный кубик ТОЙ руки атакующего, которой нанесён удар; возвращённый урон может
опускать HP кубиков руки ниже порогов (дебаффы/отсечения руки возможны); добавляется к суммарному
урону защищающегося (MEC-1.4); knockback этого удара = 0.
MEC-4.4 «Зон покрытия» как щитов нет: блок не экранирует корпус/голову; единственное условие
баффов — попадание по рукам позы (MEC-4.0).
MEC-4.5 Визуал блока — ТОЛЬКО поза + полоска стамины (TZ-6.4).
MEC-4.6 Блок в воздухе ЗАПРЕЩЁН. Во время удержания блока: ходьба ×0.5, удары любыми
слотами запрещены. Без stagger/кулдауна при Stamina=0 (M6).
MEC-4.7 Блок отсечённой рукой: при наличии кубов культи — поза культей, зона баффов = кубы
культи; при отсутствии кубов руки слот неактивен + тост (F2).

## 5. ДВИЖЕНИЕ
MEC-5.1 X — ходьба MOVE_SPEED; присед ↓: поза ниже, ХОДЬБА В ПРИСЕДЕ РАЗРЕШЕНА;
хитбоксы ВСЕГДА совпадают с визуальной моделью (воксели следуют анимации, ARC-3.2).
MEC-5.2 Прыжок JUMP_FORCE; в воздухе: удары разрешены, блок запрещён, горизонтальный
контроль отсутствует, КРОМЕ кувырка MEC-5.3.
MEC-5.3 КУВЫРОК: нажатие ←/→ в окне AIR_FLIP_WINDOW_S после старта прыжка → кувырок
длиной AIR_FLIP_DISTANCE в направлении нажатия, один за прыжок; на время кувырка
push-коллизия выключена (проход сквозь противника); после приземления за спиной
противника срабатывает разворот MEC-9.
MEC-5.4 Push-коллизия ботов: мягкое расталкивание, проход сквозь друг друга запрещён
(кроме кувырка).
