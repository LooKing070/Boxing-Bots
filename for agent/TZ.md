## 1. СУТЬ ПРОЕКТА
Полностью трёхмерный браузерный файтинг с видом сбоку (вид сбоку = позиция камеры):
гуманоидные роботы из кубов; процедурные повреждения без HP-баров (уменьшение кубов
скелета, отсечение частей вместе с внутренними компонентами, дебаффы); PvE и PvP 1v1
(P2P с хостом); 4 сцены; десктоп + мобильные, только landscape.

| Неткод | Prediction + Reconciliation (rollback ≤ ROLLBACK_MAX_FRAMES) | отзывчивость файтинга |
| UI | Lit ≥3.1 + Zustand ≥4.5 | минимальный бандл, Web Components поверх канваса |
| Сборка | Vite ≥5.2 | HMR, WASM/GLSL-плагины |
| Язык | TypeScript ≥5.4 strict | общие контракты client/server |
| Пакеты | pnpm ≥9 workspaces | монорепозиторий |
| Звук | Howler.js ≥2.2 | Web Audio, обход автоплея Safari/iOS |
| Ввод | Pointer Events API | мышь+тач, multi-touch по pointerId |

## 10. DEFINITION OF DONE И ПРИЁМКА
QA-DOD:
1. Запуск на десктопе и мобильном; адаптивный UI; тач-управление.
2. Все 4 сцены реализованы и связаны навигацией.
3. Повреждения всех уровней: обшивка, скелет (уменьшение), компоненты (пороги 60%/0%).
4. Разрушения видны на модели; HP-баров нет (урон — цифрами).
5. Надписи о повреждении компонентов — 2 сек.
6. Отсечение работает, включая внутренние компоненты (отсечённый компонент = уничтожен);
   обломки — мусор без урона.
7. Дебаффы: задержка 0.5 с; −30% силы; −40%/−50% скорости; виньетка.
8. Редактор (layout SCENES §2) создаёт удары и блоки, привязка к A–D; пресеты сохраняются;
   «сбросить всё» возвращает дефолты.
9. Блок не даёт неуязвимость: любой удар наносит урон; баффы блока действуют ТОЛЬКО при
   попадании по рукам в позе блока; стамина (тап −10, −10/с, +2/2 с); визуал — только поза
   и полоска над ботом.
10. «Укрепление» −35% (редактируемо, ≤ BLOCK_REDUCTION_MAX_PCT); «Контрудар» 8%
    (редактируемо) в случайный кубик бьющей руки атакующего.
11. Победа: нокаут (материнка/аккумулятор, включая отсечение с ними) или больший суммарный
    урон за 180 с.
12. Кнопки: A–D справа снизу, движение слева снизу; safe-area учтён.
13. PvP P2P: хост авторитетен; дисконнект хоста — отмена; гостя — 10 с и победа хоста.
14. Звуков шагов нет; звуки по материалу; ≤3 одновременных.
15. Лимиты: ≤1000 кубов/бот; ≤300 физ. тел; частицы 150/50.
16. FPS ≥30 мобильные / ≥60 десктоп; бандл ≤ BUNDLE_GZIP_MB.
17. Хитбокс кулака фиксирован (= размер кулака), не настраивается.
18. Тело процедурно изгибается/наклоняется за бьющей рукой при ударах.
19. Кувырок: триггер ←/→ в окне 0.25 с после прыжка, один за прыжок; во время кувырка
    запрещены удары/блок/управление; коллизия ВКЛЮЧЕНА; дуга (апекс ≥ рост бота + 0.5,
    длина 5.0) гарантирует перелёт стоячего противника при старте с 0–4 юнитов;
    противник может помешать перелёту прыжком (коллизия).
20. Автотurn 1.5 с + модификаторы; во время разворота заблокированы движение, удары, блок.
21. Нокдаун: отсечённая нога + попадание по внутреннему компоненту → падение 1.5 с,
    затем подъём; во время падения действия недоступны.
22. Глобальный кулдаун 200 мс между любыми ударами/блоками; возврат руки в стойку
    происходит внутри этого окна.
23. Урон удара = квадратичная функция средней длительности кадров, диапазон 2–10;
    параметра «сила» нет.
24. Удар отсечённой рукой: анимация «попытки», хитбокс = куб скелета у края культи.
25. Урон по кубикам — только при прямом контакте (без splash).
26. Реванш PvP стартует только при подтверждении обоих игроков (чек-боксы).
27. Зона параметров редактора не содержит элементов ввода (только отображение итога).
28. Бафф блока выбирается комбобоксом из двух фиксированных значений (35% / 8%).
29. Слоты блока активны всегда; зона баффов = уцелевшие кубы блокирующей руки
    (нет кубов — бафф не срабатывает за отсутствием контакта).

Чек-листы фаз:
Фаза 1: бот ≤ BOT_CUBE_LIMIT (юнит-тест); ходит/прыгает; камера следует; арена/свет по STYLE §5.
Фаза 2: тесты MEC-2 (пороги 60/0), отсечение локтя/бедра/шеи/головы (компоненты отсечены =
уничтожены); дебаффы; пулы в лимитах PERF.
Фаза 3: редактор по SCN-2 (все зоны/кнопки/комбобоксы); стамина-формула; контрудар бьёт в руку
атакующего и только при попадании по рукам; баффы не действуют при попадании в корпус; PvE дерётся.
Фаза 4: SCN-чек-листы всех сцен; звуки по таблице STYLE §6; изгиб тела за рукой виден (STY-3.5).
Фаза 5: PvP на 2 клиентах; сценарии дисконнектов NET-6; rollback-тест с лагом 150 мс.
Фаза 6: профилирование по MECHANICS §9; кросс-браузерная матрица.
