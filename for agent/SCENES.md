## 0. КАРТА НАВИГАЦИИ
[Меню] ⇄ [Редактор ударов и блоков]
[Меню] ⇄ [Настройки]
[Меню] → [Бой PvE] (кнопка «Играть с ботом»)

## 1. СЦЕНА «ГЛАВНОЕ МЕНЮ»
SCN-1.1 Кнопки (вертикальный список по центру/слева, адаптив):
«Играть с ботом», «Онлайн-бой», «Редактор удара», «Настройки», «Выход/Назад».
SCN-1.2 Фон: 3D-сцена арены (STYLE §5) с «дышащим» ботом (STYLE §3.1); камера медленно
орбитально не движется — статична с лёгким параллаксом от движения мыши/наклона (опц.).
SCN-1.3 «Онлайн-бой» открывает модальное окно (bb-modal): [Создать комнату (код)] /
[Войти по коду] / индикатор поиска матча; ошибки сети — тост (SCN-5.2).
SCN-1.4 Адаптив: на мобильных кнопки ≥ TOUCH_MIN_ACTION_PX, список сжимается в колонку
с прокруткой при нехватке высоты; safe-area учтён.
SCN-1.5 При входе с мобильного — блокировка landscape (TZ-5.9); portrait показывает
заглушку «Поверните устройство горизонтально».

## 2. СЦЕНА «РЕДАКТОР УДАРОВ И БЛОКОВ»
SCN-2.1 Раскладка: сверху/по центру — 3D-вьюпорт с ботом; снизу — панель управления
(таймлайн + слайдеры); справа — колонка слотов A–D.
SCN-2.2 Слоты: 4 вкладки A, B, C, D. В каждой: переключатель типа [Удар | Блок].
SCN-2.3 Панель удара: селектор руки (левая/правая/обе); таймлайн ключевых кадров
(добавить/удалить/перетащить кадр); слайдеры + числовые поля: углы X/Y/Z, скорость,
сила (STR_FORCE_MIN..MAX); отображение кривой Catmull-Rom; параметры duration/windup/
active/recovery, hitboxRadius, knockback — слайдерами с числовым дублем.
SCN-2.4 Панель блока: выбор позы (пресеты поз: «рука у головы», «скрещённые руки»,
«низкий блок»); зона покрытия (авто из позы, визуализация капсулой); селектор баффа
[Укрепление | Контрудар] с текстовым пояснением эффекта (MEC-4.3).
SCN-2.5 Предпросмотр: кнопки [▶ Проиграть] [⏹ Стоп]; в вьюпорте — бот выполняет действие,
линия траектории руки, полупрозрачный хитбокс в активной фазе; проигрывание циклом.
SCN-2.6 Сохранение: [Сохранить пресет] → localStorage + профиль сервера (MEC §8 STORE_*);
[Загрузить] из слота; индикация «сохранено» тостом. Валидация: незаполненные обязательные
поля — подсветка + тост, сохранение блокируется.
SCN-2.7 Кнопка [Назад] — в меню с подтверждением (bb-modal), если есть несохранённые правки.

## 3. СЦЕНА «НАСТРОЙКИ»
SCN-3.1 Секции вкладками: Графика | Звук | Управление | Сеть.
SCN-3.2 Графика: качество теней (PCF Soft / Basic / Off); лимит частиц
(Полный/Мобильный/Выкл); pixelRatio (Авто/1/1.5/2); пост-эффекты (Вкл/Выкл).
SCN-3.3 Звук: общая громкость (0–100), mute.
SCN-3.4 Управление: отображение раскладки клавиатуры (SCN-4.5); чувствительность
тач-зон (радиусы притяжения 1.0–1.5); тест-кнопки для проверки ввода.
SCN-3.5 Сеть: индикатор текущего пинга; регион лобби (список регионов Colyseus).
SCN-3.6 Всё сохраняется в localStorage мгновенно при изменении (MEC §8 STORE_SETTINGS);
кнопка [Сбросить по умолчанию].

## 4. СЦЕНА «БОЙ»
SCN-4.1 HUD-верх: [таймер обратного отсчёта MATCH_DURATION_S] [урон: N / M цифрами]
[ping — только PvP]. Никаких HP-баров (TZ-6.1).
SCN-4.2 HUD-низ-слева: D-Pad 4 кнопки (←, →, ↓ присед, ↑ прыжок), тач-таргет
≥ TOUCH_MIN_MOVE_PX; HUD-низ-справа: кнопки A, B, C, D (удар/блок по пресету слота),
тач-таргет ≥ TOUCH_MIN_ACTION_PX; визуальный отклик нажатия (scale 0.92 + подсветка);
радиусы притяжения больше иконок (SCN-5.1).
SCN-4.3 Полоска Stamina — над ботом в 3D, только при активном блоке (MEC-4.2, STYLE §7.4).
SCN-4.4 Плавающие надписи о повреждениях компонентов — над ботом, 2 сек (MEC-2.3, STYLE §4).
SCN-4.5 Клавиатура (десктоп): движение WASD/стрелки; действия J/K/L/I (альтернатива 1/2/3/4);
раскладка дублируется в Настройках (SCN-3.4).
SCN-4.6 Кнопка [Выйти] (мелкая, верх-право): PvE — возврат в меню; PvP — приравнивается к
дисконнекту по правилам NET-6 (хост вышел = отмена матча, гость вышел = 10 с ожидания).
Оверлей завершения матча: причина (нокаут / время / отмена / победа хоста по таймауту гостя),
победитель, итоговый урон обоих, кнопки [Реванш (PvE)] / [В меню].
SCN-4.7 Оверлеи ошибок сети: «Потеряно соединение… ожидание N с» (гость), «Матч отменён:
хост отключился» (NET-6); тосты о реконнекте.
SCN-4.8 Паузы в игре нет (дизайн-решение): матч непрерывен, кроме оверлеев 4.6–4.7.

## 5. СКВОЗНЫЕ UX-ПРАВИЛА
SCN-5.1 Multi-touch изоляция: левая и правая зоны боя обрабатываются независимо по pointerId;
одновременные движение+удар+блок обязательны к поддержке (≥3 точек).
SCN-5.2 Тосты (bb-toast): низ-центр, 2–3 сек, не перекрывают кнопки; стек ≤2.
SCN-5.3 Модальные окна (bb-modal): подтверждение выхода/сброса/несохранённых правок.
SCN-5.4 Feedback любого нажатия: визуальный отклик ≤50 мс; звуковой — только боевые события
(STYLE §6), клики UI без звука.
SCN-5.5 Safe-area: все нижние/боковые отступы через env(safe-area-inset-*).
SCN-5.6 Соотношения сторон: HUD anchored к углам; при ultrawide — центрирование игровой
области камеры (CAM_*), HUD не растягивается.
