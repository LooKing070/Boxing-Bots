## 1. СЦЕНА «ГЛАВНОЕ МЕНЮ»
SCN-1.1 Кнопки: «Играть с ботом», «Онлайн-бой», «Редактор удара», «Настройки», «Выход/Назад».
SCN-1.2 Фон: 3D-арена (STYLE §5) с «дышащим» ботом (STYLE §3.1).
SCN-1.3 «Онлайн-бой»: bb-modal [Создать комнату (код)] / [Войти по коду] / поиск матча;
ошибки сети — тост (SCN-5.2).
SCN-1.4 Адаптив: кнопки ≥ TOUCH_MIN_ACTION_PX; колонка с прокруткой при нехватке высоты; safe-area.
SCN-1.5 Landscape-lock (TZ-5.9); portrait-заглушка «Поверните устройство горизонтально».

## 2. СЦЕНА «РЕДАКТОР УДАРОВ И БЛОКОВ» (layout строго по зонам)
SCN-2.0 Зоны экрана: СЛЕВА СВЕРХУ — параметры; СЛЕВА СНИЗУ — кадры; СЕРЕДИНА НИЗ —
слоты/тип/сброс; СПРАВА СНИЗУ — действия; ОСТАВЛЬНОЕ ПРОСТРАНСТВО — 3D-вьюпорт.
Панели не перекрывают вьюпорт больше отведённых зон; стиль STYLE §7.

SCN-2.1 СЛЕВА СВЕРХУ — «Параметры удара/блока» (слайдеры + числовые поля):
• Тип «Удар»: СИЛА (= урон за попадание, DAT STR_FORCE_MIN..MAX); СКОРОСТЬ
(скорость движения кулака по кадрам, юнит/с, DAT STR_SPEED_MIN..MAX).
• Тип «Блок»: УМЕНЬШЕНИЕ УРОНА (%) (DAT 0..BLOCK_REDUCTION_MAX_PCT);
ВОЗВРАЩАЕМЫЙ УРОН (%) (DAT 0..BLOCK_RETURN_MAX_PCT).
Активно поле, соответствующее выбранному бафу (SCN-2.2); неактивное — серое с подсказкой.

SCN-2.2 СЛЕВА СНИЗУ — «Кадры траектории удара/блока»:
• Кнопка [Добавить кадр] — доступна только для типа «Удар».
• Комбобокс «Бафф блока»: (Усиление, Контратака) — виден для типа «Блок».
• Комбобокс «Рука удара/блока»: (правая, левая, обе руки).
• Плитки кадров: для «Удара» — столько, сколько добавил игрок (список с прокруткой,
у плитки кнопка удаления); для «Блока» — ВСЕГДА ровно одна плитка.
• Каждая плитка: ползунки X, Y, Z — координаты точки, до которой кулак летит ПО ПРЯМОЙ
от точки предыдущего кадра. Начальная точка (кулаки в обычной стойке) есть всегда,
не редактируется и не отображается плиткой.
• Визуализация выбранной плитки: маркер точки в вьюпорте + линия сегмента от предыдущей.

SCN-2.3 СЕРЕДИНА НИЗ:
• Кнопки выбора слота: [A] [B] [C] [D] (подсветка активного).
• Кнопки выбора типа: [Удар] [Блок].
• Кнопка [Сбросить всё] — сбрасывает параметры ВЫБРАННОГО слота до значений по умолчанию
(DAT DEFAULT_*), с подтверждением (bb-modal).

SCN-2.4 СПРАВА СНИЗУ:
• [Проиграть во вьюпорте] — бот выполняет текущий пресет: видны траектория кулака
(полилиния кадров), фиксированный хитбокс кулака (полупрозрачный куб FIST_HITBOX_SIZE),
изгиб тела за рукой (STY-3.5); для блока — принятие позы; проигрывание циклом до остановки.
• [Сохранить] — пресет слота в localStorage + профиль сервера (MEC §8 STORE_*); тост «Сохранено».
• [В меню] — переход SCN-0; при несохранённых правках — bb-modal подтверждения.

SCN-2.5 ВЬЮПОРТ (оставшееся пространство): бот в стойке, камера 3/4 спереди; сетка/маркеры
точек кадров; предпросмотр повреждений не требуется.
SCN-2.6 Валидация: диапазоны полей по DAT; у блока ровно 1 кадр; у удара ≥1 кадра;
сохранение блокируется при ошибках с подсветкой полей и тостом.

## 3. СЦЕНА «НАСТРОЙКИ»
SCN-3.1 Вкладки: Графика | Звук | Управление | Сеть.
SCN-3.2 Графика: тени (PCF Soft/Basic/Off); лимит частиц (Полный/Мобильный/Выкл);
pixelRatio (Авто/1/1.5/2); пост-эффекты (Вкл/Выкл).
SCN-3.3 Звук: громкость 0–100, mute.
SCN-3.4 Управление: раскладка клавиатуры (SCN-4.5); чувствительность тач-зон 1.0–1.5; тест-кнопки.
SCN-3.5 Сеть: индикатор пинга; регион лобби.
SCN-3.6 Автосохранение в localStorage (STORE_SETTINGS); [Сбросить по умолчанию].

## 4. СЦЕНА «БОЙ»
SCN-4.1 HUD-верх: [таймер MATCH_DURATION_S] [урон: N / M цифрами] [ping — PvP]. HP-баров нет (TZ-6.1).
SCN-4.2 HUD-низ-слева: D-Pad (←, →, ↓ присед, ↑ прыжок), тач ≥ TOUCH_MIN_MOVE_PX;
HUD-низ-справа: [A][B][C][D] (удар/блок пресета слота), тач ≥ TOUCH_MIN_ACTION_PX;
отклик нажатия scale 0.92 + подсветка; радиусы притяжения больше иконок.
SCN-4.3 Полоска Stamina над ботом — только при активном блоке (MEC-4.2, STYLE §7.4).
SCN-4.4 Надписи о повреждениях компонентов — над ботом, 2 сек (MEC-2.3, STYLE §4).
SCN-4.5 Клавиатура: движение WASD/стрелки; действия J/K/L/I (или 1/2/3/4); дубль в SCN-3.4.
SCN-4.6 [Выйти] (мелкая, верх-право): PvE — в меню; PvP = дисконнект по NET-6.
Оверлей завершения: причина (нокаут/время/отмена/победа хоста по таймауту гостя/ничья),
победитель, итоговый урон обоих, [Реванш (PvE)] / [В меню].
SCN-4.7 Оверлеи сети: «Потеряно соединение… ожидание N с» (гость); «Матч отменён: хост
отключился»; тосты реконнекта.
SCN-4.8 Паузы нет: матч непрерывен вне оверлеев 4.6–4.7.

## 5. СКВОЗНЫЕ UX-ПРАВИЛА
SCN-5.1 Multi-touch изоляция по pointerId; одновременно движение+удар+блок (≥3 точки).
SCN-5.2 Тосты: низ-центр, 2–3 с, стек ≤2, не перекрывают кнопки.
SCN-5.3 bb-modal: подтверждения выхода/сброса/несохранённых правок.
SCN-5.4 Feedback нажатия ≤50 мс визуальный; звук — только боевые события (STYLE §6).
SCN-5.5 Safe-area: env(safe-area-inset-*).
SCN-5.6 Ultrawide: центрирование игровой области камеры, HUD не растягивается.
