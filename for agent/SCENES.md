## 1. СЦЕНА «ГЛАВНОЕ МЕНЮ»
SCN-1.1 Кнопки: «Играть с ботом», «Онлайн-бой», «Редактор удара», «Настройки», «Выход/Назад».
SCN-1.2 Фон: 3D-арена (STYLE §5) с «дышащим» ботом (STYLE §3.1).
SCN-1.3 «Онлайн-бой»: bb-modal [Создать комнату (код)] / [Войти по коду] / поиск матча;
ошибки сети — тост (SCN-5.2).
SCN-1.4 Адаптив: кнопки ≥ TOUCH_MIN_ACTION_PX; колонка с прокруткой при нехватке высоты; safe-area.
SCN-1.5 Landscape-lock (TZ-5.9); portrait-заглушка «Поверните устройство горизонтально».

## 2. СЦЕНА «РЕДАКТОР УДАРОВ И БЛОКОВ»
SCN-2.0 Зоны: СЛЕВА СВЕРХУ параметры; СЛЕВА СНИЗУ кадры; СЕРЕДИНА НИЗ слоты/тип/сброс;
СПРАВА СНИЗУ действия; ОСТАЛЬНОЕ — 3D-вьюпорт.
SCN-2.1 СЛЕВА СВЕРХУ — «Параметры»:
• Удар: СИЛА (2–10, = урон на минимальной скорости кадров); справочное поле
«урон при текущей скорости: N» (пересчёт по MEC-3.2).
• Блок: УМЕНЬШЕНИЕ УРОНА (%) (0–BLOCK_REDUCTION_MAX_PCT); ВОЗВРАЩАЕМЫЙ УРОН (%)
(0–BLOCK_RETURN_MAX_PCT); активно поле выбранного баффа, второе серое.
SCN-2.2 СЛЕВА СНИЗУ — «Кадры»:
• [Добавить кадр] (только удар; максимум FRAMES_MAX=6).
• Комбобокс «Бафф блока» (Усиление, Контратака); комбобокс «Рука» (правая, левая, обе).
• Плитки кадров (у блока всегда 1): ползунки X, Y, Z (диапазон ±EDITOR_RANGE от стойки;
сегменты — прямые от предыдущей точки) + ползунок ДЛИТЕЛЬНОСТЬ кадра 0.2–1.0 с.
• Начальная точка = стойка, не редактируется. Визуализация выбранной плитки: маркер + линия.
SCN-2.3 СЕРЕДИНА НИЗ: [A][B][C][D]; [Удар][Блок]; [Сбросить всё] (дефолты DAT DEFAULT_*,
с подтверждением).
SCN-2.4 СПРАВА СНИЗУ: [Проиграть во вьюпорте] (траектория, хитбокс кулака, изгиб тела;
цикл до остановки); [Сохранить] (localStorage + профиль); [В меню] (подтверждение при
несохранённых правках).
SCN-2.5 Вьюпорт: бот в стойке, камера 3/4 спереди, маркеры кадров.
SCN-2.6 Валидация: диапазоны DAT; у блока 1 кадр; у удара 1–6 кадров; ошибки — подсветка + тост.

## 3. СЦЕНА «НАСТРОЙКИ»
SCN-3.1 Вкладки: Графика | Звук | Управление | Сеть.
SCN-3.2 Графика: тени (PCF Soft/Basic/Off); лимит частиц (Полный/Мобильный/Выкл);
pixelRatio (Авто/1/1.5/2); пост-эффекты (Вкл/Выкл).
SCN-3.3 Звук: громкость 0–100, mute.
SCN-3.4 Управление: раскладка клавиатуры (SCN-4.5); чувствительность тач-зон 1.0–1.5; тест-кнопки.
SCN-3.5 Сеть: индикатор пинга; регион лобби.
SCN-3.6 Сложность ИИ (PvE): [Лёгкая][Средняя][Сложная], дефолт Средняя; сохраняется
в STORE_SETTINGS.
SCN-3.7 Автосохранение настроек в localStorage; [Сбросить по умолчанию].

## 4. СЦЕНА «БОЙ»
SCN-4.1 HUD-верх: [таймер MATCH_DURATION_S] [урон: N / M цифрами] [ping — PvP]. HP-баров нет (TZ-6.1).
SCN-4.2 HUD-низ-слева: D-Pad (←, →, ↓ присед, ↑ прыжок), тач ≥ TOUCH_MIN_MOVE_PX;
HUD-низ-справа: [A][B][C][D] (удар/блок пресета слота), тач ≥ TOUCH_MIN_ACTION_PX;
отклик нажатия scale 0.92 + подсветка; радиусы притяжения больше иконок.
SCN-4.3 Полоска Stamina над ботом — только при активном блоке (MEC-4.2, STYLE §7.4).
SCN-4.4 Надписи о повреждениях компонентов — над ботом, 2 сек (MEC-2.3, STYLE §4).
SCN-4.5 Клавиатура: движение WASD/стрелки; действия J/K/L/I (или 1/2/3/4); дубль в SCN-3.4.
SCN-4.6 [Выйти] (верх-право): PvE — в меню; PvP = дисконнект по NET-6.
Оверлей завершения: причина, победитель, итоговый урон, [В меню]; PvE: [Реванш];
PvP: чек-бокс [Реванш] с индикацией статуса соперника («не подтвердил / подтвердил»);
матч перезапускается хостом только когда оба отметили чек-бокс (NET-2.6).
SCN-4.7 Оверлеи сети: «Потеряно соединение… ожидание N с» (гость); «Матч отменён: хост
отключился»; тосты реконнекта.
SCN-4.8 Паузы нет: матч непрерывен вне оверлеев 4.6–4.7.

## 5. СКВОЗНЫЕ UX-ПРАВИЛА
SCN-5.1 Multi-touch изоляция по pointerId; одновременно движение+удар+блок (≥3 точки).
SCN-5.2 Тосты: низ-центр, 2–3 с, стек ≤2, не перекрывают кнопки.
SCN-5.3 bb-modal: подтверждения выхода/сброса/несохранённых правок.
SCN-5.4 Feedback нажатия ≤50 мс визуальный; звук — только боевые события (STYLE §6).
SCN-5.5 Safe-area: env(safe-area-inset-*).
SCN-5.6 Ultrawide: центрирование игровой области камеры, HUD не растягивается.
