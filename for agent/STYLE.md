# СТИЛЬ И ВИЗУАЛ — «Boxing-Bots»
Файл: STYLE.md | Версия 5.1

## 0. РЕФЕРЕНСЫ И ИНТЕРПРЕТАЦИЯ
STY-0.1 Приложение-референсы: (1) арена; (2) бот с обшивкой — 5 ракурсов (фронт, зад, бок,
3/4 сверху-спереди, 3/4 снизу-спереди); (3) скелет — 6 ракурсов (фронт, зад, бок, 3/4 сверху,
3/4 снизу, 3/4 сзади-сверху).
STY-0.2 Из референсов — пропорции, силуэт, членение, композиция арены; цвета/материалы — только §2.
STY-0.3 Целевой вид: массивная голова-куб с глазами-прорезями, широкая грудь, сегментированные
конечности с видимыми суставными вставками скелета.

## 1. АНАТОМИЯ БОТА
STY-1.1 Тело: 3 части — грудь, живот, таз; руки = ноги по длине; ≤ BOT_CUBE_LIMIT кубов.
STY-1.2 Схема обшивки (9×16): Р16-14 голова 3×3; Р13 шея 2×1; Р12 плечи+наплечники;
Р11-9 грудь 5×3 + руки; Р8-6 живот 4×3; Р5-4 таз 4×2; Р3-2 ноги; Р1 стопы.
STY-1.3 Схема скелета (7×16): голова 2×2; шея 1×1; перекладина плеч 5×1; стойка груди;
стойка живота; перекладина таза 2×1; ноги-стойки; стопы 2×1.
STY-1.4 Бюджет: обшивка 384 + скелет 68 + компоненты ~40 + суставы ≈ 500–550 кубов.
STY-1.5 Суставные акценты JOINT_SIZE цвета скелета: плечи, локти, кисти, бёдра, колени, стопы.
STY-1.6 Внутренности (видны через пробоины): материнка — плоскость 2×2×1 с дорожками и
микросхемами; гироскоп — 3 кольца-кардана; аккумулятор — блок с полосами-индикаторами;
камеры — два светящихся «глаза».

## 3. АНИМАЦИИ (процедурные)
STY-3.1 «Дыхание» (меню/idle): синусоида BREATH_AMP/BREATH_HZ, фаза по высоте.
STY-3.2 Ходьба: синусоида ног WALK_AMP/WALK_HZ (масштаб от скорости).
STY-3.3 Удары/блоки: из пресетов редактора; дефолты MEC-3.4.
STY-3.4 Дебафф-анимации: wobble гироскопа (±3° хаотично); «падения» (крен до 20° при ударах)
при уничтоженном гироскопе; глитч материнки — RGB shift + смещения 1–2 кубов на 1–2 кадра.
STY-3.5 ИЗГИБ ТЕЛА ЗА РУКОЙ: при ударе корпус и голова процедурно наклоняются/скручиваются
в сторону бьющей руки пропорционально выносу кулака от стойки (реалистичное следование тела
за рукой); «обе руки» — симметричный наклон; при возврате в стойку тело плавно выпрямляется.
Поза блока — корпус слегка подан за блокирующими руками.
STY-3.6 Разворот: плавный поворот корпуса на 180° за время MEC-9.1; в это время руки
опущены в защитную нейтральную позу.
STY-3.7 Кувырок: сальто вперёд/назад через голову за время полёта сегмента; трейл не нужен.
STY-3.8 Нокдаун: падение на спину с вращением, лёгкие искры из суставов; подъём за 0.4 с
по окончании KNOCKDOWN_S.
STY-3.9 Шатание при уничтоженном гироскопе: амплитуда наклона корпуса ±6°, период ~0.8 с,
фаза случайна (сильнее, чем wobble повреждённого).
STY-3.10 Удар культей: корпус тянется к цели, остаток руки выдвигается до предела;
хитбокс-куб скелета визуализируется только в отладочном режиме.

## 4. ПОВРЕЖДЕНИЯ И VFX
STY-4.1 Обшивка: почернение куба в точке удара, сколы, искры P_HIT_ARMOR_MIN..MAX #FFCC00 (0.05).
STY-4.2 Скелет: искры #FF3300 P_HIT_SKEL_MIN..MAX + 1–2 обломка; деформация SKELETON_HIT_DEFORM.
STY-4.3 COMPONENT_DAMAGED: 8–12 частиц цвета компонента + 2–3 обломка + надпись 2 с.
STY-4.4 COMPONENT_DESTROYED: 15–20 частиц + 5–8 крупных обломков + PointLight-вспышка (0.2 с) + «дыра».
STY-4.5 LIMB_DETACHED: отсечённая часть летит целостным кластером с вращением; отсечённый
внутренний компонент летит вместе с частью (или отдельным обломком, если несущая часть не
отсечена целиком), его свечение гаснет за 0.5 с; исчезает по DEBRIS_LIFETIME_S.
STY-4.6 Частицы: THREE.Points/InstancedMesh, жизнь PARTICLE_LIFE_S, гравитация+затухание.

## 6. ЗВУК
STY-6.1 Шагов НЕТ (TZ-6.3); блок без звуков активации (TZ-6.4).
STY-6.2 Материал → тембр: обшивка — металлический лязг/скрежет; скелет — глухой удар
деформируемого металла; материнка — электротреск/помехи; аккумулятор — пластиковый удар + НЧ-гул;
гироскоп — высокий звон механизмов; камеры — звон стекла + ВЧ-писк.
STY-6.3 COMPONENT_DESTROYED — громкий взрыв + вспышка света.
STY-6.4 Микс ≤3 одновременных; короткий decay; UI-клики без звука.
